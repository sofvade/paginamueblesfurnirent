# Furnirent

Proyecto Next.js con páginas de Inicio, Servicios y Contacto. Incluye Tailwind CSS, componentes accesibles y endpoint `/api/contact`.

## Requisitos

- Node.js 18+
- npm

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

## Construcción

```bash
npm run build
```

## Despliegue en Vercel

1. Inicia sesión en Vercel (`npx vercel login`).
2. Ejecuta:

```bash
npm run deploy
```

## Sitemap y robots

Los archivos `public/sitemap.xml` y `public/robots.txt` están listos para SEO.
